M94 / PLY Splitter

Разделяет большой PLY на отдельные файлы по 10 МиБ. Никаких ZIP и архивов. Обработка происходит локально в браузере — исходный файл никуда не отправляется.

Выбери файл, чтобы начать.

Каждая часть скачается отдельным файлом e30_part_001.bin, e30_part_002.bin и т. д. Также скачается manifest.txt с информацией о порядке частей. Если Safari спросит разрешение на несколько загрузок — разреши их для этого сайта. На GitHub загружай сами BIN-файлы, не архив.
