# Модели мини-игры

Загружай сюда 3D-модели для новой мини-игры.

Предпочтительный формат: GLB (`.glb`). По возможности используй короткие понятные имена файлов латиницей, например `character.glb`, `dresser.glb`, `keys.glb`, `mirror.glb`.

Не загружай сюда файлы открытки или старого проекта BMW E30.
